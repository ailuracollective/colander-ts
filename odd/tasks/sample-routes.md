# One route per React example

## Objective

Represent every sample in the React example as its own addressable route
(`/samples/<sampleId>`) instead of component state inside `App.tsx`, so a
sample is shareable, linkable, and reachable with browser history. An unknown
id is a 404 that lists the available samples rather than a silent fallback.

## Completed scope

- [x] **T1 — Add the sample route.** `src/routes/samples.$sampleId.tsx` resolves
  the id against the sample list, calls `notFound()` when it is unknown, and
  renders the app with that sample. `src/routeTree.gen.ts` is regenerated by the
  router plugin, not hand-edited.
- [x] **T2 — Move sample selection out of component state.** `App.tsx` receives
  the selected sample as a prop and navigates on change instead of holding a
  `useState`. The `/` route keeps rendering the default sample with no redirect.
- [x] **T3 — Render the not-found screen.** The router's
  `defaultNotFoundComponent` lists every sample as a link to its own route,
  built from the same shadcn primitives as the rest of the page.
- [x] **T4 — Cover the routing contract.** Every sample id resolves to a route,
  an unknown id returns 404 through the SSR request handler, and a known id
  returns 200.

## Decisions

- Route shape is `/samples/:sampleId`. A query parameter was rejected: it is not
  an addressable route per sample and pollutes browser history.
- Unknown ids are a 404 with the list, not a fallback to the default sample: a
  mistyped URL must not silently render something other than what was asked for.
- `findSample` keeps its existing fallback semantics for callers that want them;
  the route uses a lookup that can report "not found".

## Implementation notes

- `notFound()` in `@tanstack/react-router@1.170.38` returns a `NotFoundError`;
  it must be thrown. It is thrown from `beforeLoad`, not from the component
  body: a not-found raised during render never reaches the SSR status path and
  the response would be 200.
- `App.tsx` still calls `findSample` (which falls back to the BMI sample) because
  `beforeLoad` already guarantees a known id. The fallback is unreachable, not
  relied upon.
