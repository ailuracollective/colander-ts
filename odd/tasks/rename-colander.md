# Rename the TypeScript binding to colander

## Objective

Replace the former package and ABI naming with the published lowercase
`colander` Rust crate (`0.1.0`) throughout the TypeScript binding, its build
pipeline, tests, package metadata, lockfile, and documentation.

## Completed scope

- [x] **T1 — Migrate public API and ABI.** The package is named
  `@ailuracode/colander`; the public loader is `colander.load()` and returns an
  object with the existing method surface. No compatibility class is exported.
  All C ABI calls use the `colander_*` symbols, and there is no last-panic
  dependency.
- [x] **T2 — Migrate artifact build and distribution.** `wasm/colander.wasm` is
  bundled and loaded through `new URL(..., import.meta.url)`. The build script
  downloads and verifies the exact crates.io archive, checks archive safety,
  builds the release WebAssembly target with Cargo, validates the module, and
  copies the artifact. The unavailable linked package and workspace override are
  removed.
- [x] **T3 — Update tests and documentation.** Boundary tests, optional vector
  discovery, package metadata, lockfile, README, comments, and naming are
  updated. Vectors use a sibling `colander` checkout or
  `COLANDER_VECTORS` and skip when unavailable.

## Added Vite+ scope

- [x] **T4 — Migrate the complete toolchain.** Pin the current Vite+ release,
  configure the root `vite.config.ts`, move Vitest imports to `vite-plus/test`,
  use the managed pnpm overrides, and route lint, format, type-aware checks,
  tests, task execution, and library packaging through Vite+.
- [x] **T5 — Enforce maximum Ox quality gates.** Enable every supported Oxlint
  category and plugin, deny warnings, cap warnings at zero, report unused
  suppressions, enable type-aware lint/type-check, and apply strict deterministic
  Oxfmt settings. Fix findings instead of adding broad suppressions.
